## ✨ Cos'è Text-Transfer?

**Text-Transfer** è uno strumento web minimalista che ti permette di scrivere un testo e generare un **QR Code** corrispondente. Basta inquadrare il codice con qualsiasi smartphone per visualizzare immediatamente il contenuto.

Perfetto per:

- Condividere rapidamente testo, link o note tra dispositivi diversi
- Trasferire informazioni a qualcuno senza digitare
- Condividere link tra pc e smartphone senza login e senza app esterne
